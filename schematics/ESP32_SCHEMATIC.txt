# Esquema de Ligação do ESP32 - ArdPix

## Lista de Componentes

- 1x ESP32 DevKit (NodeMCU ou similar)
- 1x Buzzer Ativo 5V
- 2x LEDs 5mm (1 verde, 1 vermelho)
- 2x Resistores 220Ω (1/4W)
- 1x Protoboard 400 pontos
- Jumpers macho-macho

### 3. LED Verde de Status (GPIO 5)
┌────────┐      ┌────────┐      ┌──────┐
│  ESP32 │      │ 220Ω   │      │ LED  │
│        │      │        │      │Verde │

│        │                      │      │
│  GND   ├──────────────────────┤ -    │
│        │                      └──────┘
└────────┘

Cálculo da resistência:
V_ESP32 = 3.3V
V_LED = 2.0V (típico LED verde)
I_LED = 10mA (corrente desejada)
R = (3.3 - 2.0) / 0.010 = 130Ω
Usar resistor comercial: 220Ω (limita corrente a ~6mA, seguro)

## Instruções de Montagem

### Passo 1: Preparar Protoboard
1. Conecte a trilha GND (-) a um ponto comum
2. Não use a trilha Vcc (+) neste projeto

### Passo 2: Montar ESP32
1. Insira o ESP32 no centro da protoboard
2. Certifique-se de deixar espaço nas laterais
3. Pressione firmemente para fazer contato

### Passo 3: LED Verde (Status)
1. Identifique o pino longo do LED (anodo +)
2. Insira o LED na protoboard:
   - Pino longo em uma linha
   - Pino curto na linha do GND ou próximo
3. Conecte resistor 220Ω:
   - Um lado ao pino longo do LED
   - Outro lado livre
4. Conecte jumper:
   - Do GPIO 5 ao resistor
   - Do pino curto do LED ao GND

### Passo 4: LED Vermelho (Erro)
1. Repita o processo do LED verde
2. Use GPIO 18 ao invés de GPIO 5

### Passo 5: Buzzer
1. Identifique os pinos do buzzer
   - Pino com marcação "+" ou lado com adesivo = positivo
2. Conecte:
   - Positivo (+) ao GPIO 4
   - Negativo (-) ao GND

### Passo 6: Verificar Conexões
Use multímetro para verificar:
- GND está conectado corretamente
- Não há curto-circuito entre pinos
- Resistores estão no valor correto (220Ω)

### Passo 7: Programar ESP32
1. Conecte cabo USB ao computador
2. Faça upload do código
3. Abra Serial Monitor
4. Verifique mensagens de boot

### Passo 8: Testar
1. WiFi conectou? → LED verde deve acender
2. MQTT conectou? → Buzzer deve apitar 1 vez
3. Recebeu pagamento? → LED pisca, buzzer apita

## Troubleshooting

### LEDs não acendem
- Verifique polaridade (pino longo = +)
- Verifique resistor está conectado
- Teste LED com multímetro
- Verifique código (pinMode, digitalWrite)

### Buzzer não apita
- Verifique se é buzzer ativo (não passivo)
- Teste com 3.3V direto do ESP32
- Verifique polaridade
- Tente outro pino GPIO

### ESP32 não liga
- Verifique alimentação USB
- Tente outro cabo USB
- Verifique se ESP32 está bem encaixado
- Teste em outra porta USB

### Programa não carrega
- Pressione botão BOOT durante upload
- Verifique porta COM/ttyUSB correta
- Verifique driver CH340/CP2102 instalado
- Tente velocidade menor (115200 → 9600)

## Especificações Técnicas

### ESP32
- Tensão de operação: 3.3V
- Corrente máxima por pino: 12mA (recomendado)
- Corrente máxima total: 200mA

### LEDs
- Tensão forward: ~2.0V (verde), ~1.8V (vermelho)
- Corrente recomendada: 5-10mA
- Corrente máxima: 20mA

### Buzzer
- Tensão: 3-5V
- Corrente: ~30mA
- Frequência: ~2kHz (buzzer ativo)

### Resistores
- Valor: 220Ω
- Potência: 1/4W
- Tolerância: 5% (ouro)

## Código de Cores dos Resistores

220Ω = Vermelho, Vermelho, Marrom, Ouro
```
┌─────────────┐
│ ▓▓▓░░▓░░    │

│ ▓▓▓░░▓░░ ██ │
│ ▓▓▓░░▓░░    │
│ ▓▓▓░░▓░░    │
└─────────────┘
  │ │ │   │
  │ │ │   └─── Ouro (5%)
  │ │ └─────── Marrom (×10)
  │ └───────── Vermelho (2)
  └─────────── Vermelho (2)

  22 × 10 = 220Ω
```
